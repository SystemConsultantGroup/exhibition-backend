== 공통 응답 형식

이 API는 엔드포인트 성격에 따라 아래 응답 형식을 사용합니다.

=== 목록 조회 응답 (페이지네이션)

목록 조회 API는 `items`, `page`, `pageSize`, `total`을 포함한 페이지네이션 구조를 사용합니다.

[source,json]
----
{
  "items": [
    {
      "...": "리소스 필드"
    }
  ],
  "page": 1,
  "pageSize": 20,
  "total": 120
}
----

=== 단건 조회 응답

단건 조회 API는 해당 리소스 객체를 그대로 반환합니다.

[source,json]
----
{
  "id": "uuid",
  "...": "리소스 필드"
}
----

=== 파일 다운로드 응답

파일 조회 API(`/media/{id}`)는 JSON이 아닌 바이너리 본문을 반환하며, `Content-Type`은 파일 형식에 따라 달라집니다.

== 전시(Exhibition)

=== 프론트엔드 표시 설정

전시 조회 응답에는 아래 테넌트별 설정이 포함됩니다.
두 설정은 프론트엔드에서만 적용하며, 백엔드의 작품 응답 데이터나 필터링·정렬 동작은 변경하지 않습니다.

* `showAwards`: 수상작 탭과 수상 아이콘 표시 여부입니다. 기본값은 `true`입니다.
* `defaultToLatestEventPeriod`: 초기 조회에서 최신 회차를 기본 선택할지 여부입니다. 기본값은 `false`입니다.
  최신 회차는 `createdAt` 기준이며, 프론트엔드가 회차를 선택하여 기존 `eventPeriodId` 필터로 요청합니다.

관리자 전시 생성 요청에서 설정을 생략하거나 `null`로 전달하면 기본값을 적용합니다.
수정 요청에서 설정을 생략하거나 `null`로 전달하면 기존 값을 유지합니다.

=== 카테고리 생성 및 삭제

`POST /admin/categories`는 `{"name":"카테고리명"}`으로 생성하며 201을 반환합니다.
`DELETE /admin/categories/{id}`는 비어 있는 카테고리를 삭제하고 204를 반환합니다.
두 API는 `X-Exhibition-Id`와 해당 전시 관리 권한이 필요합니다. 이름/슬러그 충돌 또는
작품이 참조 중인 카테고리 삭제는 409입니다.

=== 항목 수정

기존 JSON PUT과 함께 `multipart/form-data` PUT을 지원합니다. multipart는 생성과 같은
`request` JSON 파트 및 선택적 `thumbnailFile`, `posterFile`, `presentationVideoFile` 파트를 받습니다.
파일 생략 시 기존 연결은 유지됩니다. `removeThumbnail`, `removePoster`,
`removePresentationVideo`를 true로 지정하면 해당 연결을 제거합니다. 같은 슬롯의 제거와 교체는
동시에 요청할 수 없습니다. `classificationIds` 생략/null은 기존 분류 유지, 빈 배열은 전체 해제,
ID 배열은 해당 전시회 분류로 전체 교체입니다. 분류 지정은 생성 요청에서도 지원됩니다.

=== 항목 일괄 등록

기존 multipart 계약(`file`, 반복 `mediaFiles`)을 유지합니다. Excel은 10 MiB/1000행,
기본 multipart 제한은 파일당 500 MiB, 총 10 GiB, 3001파트입니다.
전체 입력을 저장 전에 검증하고 카테고리/분류 조회를 캐시하며 DB 저장은 JDBC 배치로 처리합니다.
MinIO 전송만 제한된 공유 작업자(`APP_UPLOAD_WORKERS`, 기본 4)에서 병렬 수행합니다.
엔티티/DB 작업은 호출 트랜잭션 스레드에 남고 실패/롤백 시 전송 객체를 정리합니다.
`X-Upload-Id` 요청 헤더는 선택 사항이며 응답에서 반환합니다.

매니저의 `BULK_UPLOAD_API_BASE_URL`로 공개 API 주소를 지정하면 브라우저에서 직접 업로드할 수
있습니다. 이때 API CORS의 관리자 호스트와 게이트웨이 업로드 제한도 설정해야 합니다.
미설정 매니저는 기존 프록시를 사용합니다. 상세 운영 설정은 README를 참고하세요.
